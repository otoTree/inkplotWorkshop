# 剧集画面风格预设 Spec

## Why
当前项目的画面风格主要依赖自由填写的 `artStyle` / `characterArtStyle` / `sceneArtStyle`，缺少一个稳定、可复用的风格入口。用户现在需要明确支持“海外真人剧、国内真人剧、国内 3DCG 剧”三种风格，并要求三套提示词链路分开维护，避免不同风格的措辞互相污染。

## What Changes
- 新增一个项目级“剧集画面风格预设”字段，用户可直接在项目创建和编辑时选择“海外真人剧 / 国内真人剧 / 国内 3DCG 剧”。
- 将现有自由文本风格能力调整为以“风格预设”驱动，核心 AI 提示词按预设分为三套独立策略，而不是只拼接不同风格描述。
- 为项目详情生成、资产提取、图片生成、分镜生成等链路定义统一的风格解析入口，确保同一项目的所有下游生成都使用同一套风格规则。
- 明确旧项目兼容策略：历史项目在未设置新预设时，保持可读可编辑，并提供安全兜底，避免生成流程中断。

## Impact
- Affected specs: 项目配置、AI 提示词编排、资产生成、分镜生成
- Affected code: `src/types/index.ts`、`src/lib/api.ts`、`src/lib/prompts.ts`、`src/components/dashboard/ProjectDialog.tsx`、`src/components/dashboard/ProjectOverview.tsx`、`src/components/assets/AssetGallery.tsx`、`src/components/storyboard/StoryboardEditor.tsx`、相关 API 路由

## ADDED Requirements
### Requirement: 用户可选择剧集画面风格预设
系统 SHALL 在项目创建和编辑流程中提供一个明确的剧集画面风格预设选择器，且仅提供以下三个可选值：
- 海外真人剧
- 国内真人剧
- 国内 3DCG 剧

#### Scenario: 创建项目时选择风格
- **WHEN** 用户新建项目并选择其中一种剧集画面风格
- **THEN** 系统保存该预设到项目数据中
- **AND** 后续 AI 生成链路默认读取该预设，而不是依赖用户手输风格文案

#### Scenario: 编辑项目时查看和修改风格
- **WHEN** 用户打开已有项目的编辑弹窗
- **THEN** 系统展示当前已保存的剧集画面风格预设
- **AND** 用户可以切换到另外两种预设之一并保存

### Requirement: 三种风格使用隔离的提示词策略
系统 SHALL 为“海外真人剧、国内真人剧、国内 3DCG 剧”分别维护独立的提示词策略，不得只通过共享模板拼接不同的风格后缀来实现差异化。

#### Scenario: 海外真人剧生成
- **WHEN** 项目风格预设为“海外真人剧”
- **THEN** 项目详情生成、资产提取、图片生成、分镜生成均使用海外真人剧专用提示词策略
- **AND** 输出中不得混入“国内真人剧”或“国内 3DCG 剧”的专属风格约束

#### Scenario: 国内真人剧生成
- **WHEN** 项目风格预设为“国内真人剧”
- **THEN** 所有相关生成链路均使用国内真人剧专用提示词策略
- **AND** 输出中不得混入“海外真人剧”或“国内 3DCG 剧”的专属风格约束

#### Scenario: 国内 3DCG 剧生成
- **WHEN** 项目风格预设为“国内 3DCG 剧”
- **THEN** 所有相关生成链路均使用国内 3DCG 剧专用提示词策略
- **AND** 输出中允许出现符合 3DCG 目标风格的描述
- **AND** 不得继续套用当前默认的“严格避免 3D / game CG / anime”的真人剧限制

### Requirement: 风格预设统一驱动下游生成
系统 SHALL 提供统一的风格解析与分发入口，使所有依赖视觉风格的 AI 生成流程都从同一项目字段获取风格预设。

#### Scenario: 资产提取与分镜保持一致
- **WHEN** 同一项目连续执行资产提取、图片生成和分镜生成
- **THEN** 各流程读取到同一个风格预设
- **AND** 角色、场景、分镜视频提示词中的风格表达保持一致

### Requirement: 历史项目兼容与兜底
系统 SHALL 对未设置新风格预设的历史项目提供兼容处理，避免旧数据导致 UI 报错或 AI 生成功能不可用。

#### Scenario: 打开未迁移的旧项目
- **WHEN** 用户打开一个仅包含旧版 `artStyle` / `characterArtStyle` / `sceneArtStyle` 数据但没有新预设字段的项目
- **THEN** 系统仍能正常展示项目信息
- **AND** 系统为生成链路提供稳定兜底风格
- **AND** 用户可重新选择新预设并保存

## MODIFIED Requirements
### Requirement: 项目风格配置
项目风格配置从“以自由文本为主”调整为“以预设选择为主、自由文本为辅或内部派生”。用户界面中的主入口必须是三选一预设，AI 提示词编排必须优先依据该预设决定所使用的模板与约束。

### Requirement: 图像与分镜风格约束
现有默认偏向真人写实的通用约束需要按预设重构。真人剧预设可以继续强调写实、摄影、电影感；国内 3DCG 剧预设必须允许并明确鼓励 3DCG 视觉语言，不能被全局真人剧限制覆盖。
